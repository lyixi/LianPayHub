# 后台功能优化路线图

本文档记录后台后续值得持续补齐的功能，避免迭代中遗漏。

## P0：上线前强烈建议

| 功能 | 价值 | 说明 |
|---|---|---|
| 管理员角色权限 | 降低误操作和越权风险 | 区分超级管理员、运营、财务、客服、只读 |
| APP 数据权限 | 多 APP 运营必需 | 管理员只能看到/操作授权 APP |
| 高风险操作原因结构化 | 审计更清晰 | 原因单独字段化，而不只在请求体日志里 |
| 设备码修改历史 | 设备会员业务关键 | 记录旧设备码、新设备码、原因、管理员、时间 |
| 支付宝真实验签 | 生产支付必需 | 替换当前骨架解析逻辑 |
| 支付宝真实下单参数 | 生产支付必需 | 从模拟/骨架 provider 升级为真实参数 |
| 支付宝退款接口 | 完整交易闭环 | 后台退款不应长期只靠人工标记 |
| 支付回调重放 | 排障必需 | 失败回调可后台重新处理 |
| 订单详情完整时间线 | 排查支付问题 | 加入 payload、操作人、失败原因 |
| 启动记录使用时长统计 | 产品分析 | 平均时长、总时长、异常退出统计 |

## P1：运营效率

| 功能 | 价值 | 说明 |
|---|---|---|
| APP 创建向导 | 降低配置错误 | 按标准 APP、设备码 APP、适配 APP 给默认模板 |
| APP 详情配置总览 | 快速排查 | 汇总支付配置、套餐、通知配置、最近订单、最近启动 |
| 设备详情完整聚合 | 设备码会员核心 | 展示会员、订单、启动历史、改码历史 |
| 会员变更日志 | 客服/运营常用 | 开通、续期、赠送、取消、退款影响都记录 |
| 订单搜索增强 | 排查效率 | 支持订单号、设备码、渠道交易号、手机号 |
| 设备搜索增强 | 客服效率 | 支持设备码、Device ID、用户 ID、最近启动时间 |
| 会员搜索增强 | 客服效率 | 支持设备码、用户 ID、到期时间范围、状态 |
| 批量导出任务化 | 防止大导出卡顿 | 大数据导出改异步任务 |
| 列表列显隐 | 后台体验 | 用户选择显示列 |
| 列表固定操作列 | 后台体验 | 横向滚动时操作按钮不丢 |
| 表单提交防重复 | 避免重复创建 | 保存中按钮禁用、显示 loading |
| 空状态引导 | 降低使用成本 | 没 APP 时提示先新建 APP |

## P2：数据分析

| 功能 | 价值 | 说明 |
|---|---|---|
| 实时运营看板 | 快速看业务健康 | 今日启动、今日下单、今日收入、支付成功率 |
| 支付漏斗 | 找转化问题 | 启动 → 查会员 → 下单 → 支付成功 → 会员生效 |
| 设备留存 | 判断 APP 粘性 | 次日、7 日、30 日留存 |
| 会员续费率 | 判断商业化 | 到期、续费、流失、召回 |
| 套餐收入排行 | 优化套餐 | 按 APP、套餐、渠道统计收入 |
| 支付失败率趋势 | 排查渠道 | 支付失败、回调失败、订单关闭率 |
| 退款率分析 | 风控 | 按 APP、套餐、渠道、时间维度 |
| 启动时长分析 | 产品分析 | 平均使用时长、中位数、长尾分布 |
| 异常退出估算 | 质量分析 | 有启动但没有上次退出数据的比例 |

## P3：接入体验

| 功能 | 价值 | 说明 |
|---|---|---|
| 接入向导页面 | 给其他项目/AI 使用 | 按 APP 类型生成步骤、curl、字段说明 |
| 一键生成接入包 | 提升复用 | 下载 OpenAPI + Markdown + curl 示例 |
| appId/packageId/deviceId 复制按钮 | 降低人工错误 | 列表和详情都加复制 |
| 沙箱/生产模式标识 | 防止接错环境 | APP 和支付配置显示当前模式 |
| 回调地址自检 | 支付接入必需 | 检查公网可访问、协议、路径、签名配置 |
| API 鉴权测试工具 | 接入排障 | 输入 appSecret 测试 secret/signature |
| 支付宝沙箱配置模板 | 接入效率 | 自动填充常见配置字段 |
| SDK 示例生成 | 方便其他项目 | Java、TS、Swift、Kotlin 示例 |

## P4：通知与告警

| 功能 | 价值 | 说明 |
|---|---|---|
| 回调失败告警 | 及时发现支付问题 | 短信/邮件通知管理员 |
| 支付成功率告警 | 及时发现渠道故障 | 成功率低于阈值触发 |
| 退款异常告警 | 风控 | 大额/高频退款提醒 |
| 管理员高危操作告警 | 安全 | 重置密钥、改设备码、退款成功通知 |
| 短信失败率统计 | 通知质量 | 按通道统计失败原因 |
| 邮件发送日志 | 补齐审计 | 邮件发送日志列表 |
| 通知通道故障切换 | 提高可用性 | 主通道失败自动切备用 |

## P5：安全增强

| 功能 | 价值 | 说明 |
|---|---|---|
| 强制首次改密 | 安全底线 | 默认密码登录后必须修改 |
| 密码复杂度策略 | 防弱密码 | 长度、大小写、数字、特殊字符 |
| 管理员登录验证码 | 防爆破 | 连续失败后触发验证码 |
| 管理员会话管理 | 安全运营 | 查看在线会话、强制下线 |
| JWT 黑名单/版本号 | 改密后旧 token 失效 | 密码变更后废弃旧 token |
| 敏感配置加密存储 | 生产安全 | credentialJson 加密落库 |
| 操作日志防篡改 | 审计合规 | 日志签名或只追加 |
| IP 白名单 | 后台安全 | 限制后台访问来源 |
| 管理后台 2FA | 高安全场景 | TOTP 或邮箱/短信二次验证 |
| 导出权限单独控制 | 数据安全 | 导出通常比查询风险更高 |

## P6：数据模型与稳定性

| 功能 | 价值 | 说明 |
|---|---|---|
| Flyway/Liquibase | 生产升级必需 | 替代 `ddl-auto=update` |
| 初始化 SQL 同步更新 | 防环境漂移 | 新字段、新索引都要进 SQL |
| 本地 H2 profile 固化 | 开发方便 | 完善 local 说明 |
| 数据库索引审计 | 性能 | 订单号、设备码、时间范围查询索引 |
| 分页上限统一 | 防大查询 | 后端统一限制 size |
| 慢查询日志 | 性能定位 | 后台列表和报表尤其需要 |
| 定时归档 | 控制表大小 | 回调、日志、启动记录增长快 |
| 启动记录分区 | 长期性能 | 按月/按 APP 分区或归档表 |
| 幂等键 | 防重复请求 | 启动、订单、适配上报可考虑 |
| 全局请求 ID | 排障 | 前后端、日志、回调串起来 |

## P7：云同步模块

| 功能 | 价值 | 说明 |
|---|---|---|
| 云同步后台页 | 当前后台缺口 | 文件列表、配额、使用量、删除记录 |
| 用户存储配额调整 | 运营需要 | 按用户/APP 调整空间 |
| 文件下载审计 | 安全 | 谁下载了什么 |
| 批量删除文件 | 管理能力 | 清理异常数据 |
| 文件恢复 | 软删除已有基础 | 后台恢复误删文件 |
| 冲突策略配置 | 多端同步 | 多设备同步会需要 |
| OSS 配置后台化 | 运维便利 | 当前主要靠配置文件 |

## P8：适配器模块

| 功能 | 价值 | 说明 |
|---|---|---|
| 上报 schema 管理 | 避免乱传 payload | 每种 reportType 有字段定义 |
| 上报幂等键 | 防重复处理 | sourceId + reportType + eventId |
| 上报处理规则 | 自动化 | 按 reportType 自动处理 |
| 失败重试/回执 | 系统对系统必需 | 给适配端明确结果 |
| 适配源管理 | 多来源管理 | sourceId、密钥、状态、限流 |
| 适配数据详情优化 | 可读性 | JSON 格式化展示 |

## P9：前端体验细节

| 功能 | 价值 | 说明 |
|---|---|---|
| JSON 字段格式化编辑器 | 配置体验 | payment/config/credential JSON 更好编辑 |
| JSON 校验 | 减少错误 | 保存前提示格式错误 |
| 时间范围筛选 | 查询效率 | 日志/订单常用 |
| 快捷筛选标签 | 提效 | 待支付、已支付、异常、失败 |
| 页面级刷新保留滚动 | 体验 | 刷新不跳动 |
| URL hash 路由 | 方便分享 | `/console/#orders?id=xxx` |
| 详情抽屉 | 复杂详情更合适 | 订单、设备、APP 聚合页会变长 |
| 表格密度切换 | 运营习惯 | 紧凑/舒适 |
| 全局搜索 | 后台效率 | 输入订单号/设备码/手机号快速定位 |
| 帮助提示 | 降低学习成本 | 字段旁说明、链接接入文档 |

## 当前最贴合目标的优先队列

| 顺序 | 功能 | 原因 |
|---:|---|---|
| 1 | 强制首次改密 | 安全底线 |
| 2 | 设备码修改历史 | 用户换设备可追踪 |
| 3 | 订单号/设备码搜索订单 | 排查支付宝购买问题 |
| 4 | 支付宝配置检查加强 | 避免生产配置错 |
| 5 | 公开套餐列表接口 | 设备码会员购买链路需要 |
| 6 | 设备详情显示会员 + 订单 + 启动时长 | 后台一页解决客服问题 |
| 7 | APP 接入包生成 | 给其他项目 AI 直接接入 |
| 8 | Flyway/Liquibase | 后续字段越来越多，必须规范迁移 |
