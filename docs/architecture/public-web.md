# 官网与公开接口架构

## 范围

本模块包括公司官网的品牌与产品展示、软件下载、帮助内容、SEO，以及现有的产品购买落地页。当前官网与后台位于同一 Spring Boot 项目，但静态资源、路由和权限边界独立；规模增长后可将官网构建产物单独部署至 CDN，无需复制后端领域逻辑。

旧官网功能的迁移清单、内容模型、后台运营能力和 AI 预留方案见[官网内容运营与 AI 预留](content-and-ai.md)。

## 公开入口边界

| 入口 | 状态 | 用途 |
|---|---|---|
| `/p/{slug}` | 已实现 | 转发至购买落地页前端 |
| `/public/purchase-pages/{slug}` | 已实现 | 获取已配置购买页、商品方案和可用支付渠道 |
| `/public/purchase-orders` | 已实现 | 从购买页创建订单 |
| `/api/site/v1/site` | 已实现 | 官网品牌、首页区块、能力节点、公司原则与页脚配置 |
| `/api/site/v1/products`、`/articles` | 已实现 | 已发布产品、产品演示内容和文章 |
| `POST /api/site/v1/leads` | 已实现 | 官网联系线索提交 |
| `/admin/website/media` | 已实现 | 受保护的官网图片上传、元数据维护与删除；文件由 `/files/**` 提供 |
| 下载版本 API | 后续 | 产品版本与多平台下载管理 |

`/public/**` 是交易型 Web 入口；`/api/site/v1/**` 是官网页面专用内容入口。两者不能混用，也不可通过官网接口读取后台内部数据。`/api/site/v1/**` 虽由匿名官网访问，但不作为第三方开放平台发布。

## 官网内容 API

当前已采用 `/api/site/v1/`。站点设置、产品、产品详情、文章、文章详情和线索提交已落地；下载版本接口留待后续实现：

| 方法 | 路径 | 返回内容 |
|---|---|---|
| GET | `/api/site/v1/site` | 品牌文案、首页区块、能力图、公司原则、联系方式与页脚信息 |
| GET | `/api/site/v1/products`、`/products/{slug}` | 已发布产品卡片和详情 |
| GET | `/api/site/v1/articles`、`/articles/{slug}` | 已发布文章/帮助内容 |
| POST | `/api/site/v1/leads` | 官网咨询线索提交 |
| GET | `/api/site/v1/downloads/{productSlug}` | 可公开的版本与下载地址（后续） |

所有接口只读、只返回 `PUBLISHED` 内容，设置 CDN 缓存和限流，并由管理端发布操作触发缓存失效。产品下载链接应使用受控跳转或短期签名 URL（如文件不适合永久公开）。

## 后台驱动渲染

官网 HTML 只定义布局、组件和交互，不承载可运营内容。首页通过 `/api/site/v1/site` 获取站点级内容，通过 `/api/site/v1/products` 获取产品矩阵和首屏主视觉产品，通过 `/api/site/v1/articles` 获取动态；后台分别从 `/admin/website/site`、`/products`、`/articles` 和 `/media` 管理。

媒体上传仅接受通过 MIME、扩展名、文件头、大小和图片尺寸校验的 JPEG、PNG、GIF、WebP。文件使用服务端 UUID 存储在 `website/` 前缀下，数据库保存标题、替代文本和说明；删除媒体会同时删除物理文件。multipart 请求不缓存请求体，但仍写入管理员操作审计。

首屏产品工作台中的项目名、分卷、三组章节示例、正文、输入段落与智能提示都属于 `WebsiteProduct`，随产品资料维护。站点标题、栏目说明、能力节点、公司原则、联系方式、备案和页脚属于单例 `WebsiteSiteSettings`。前台绑定使用纯文本写入，不执行后台内容中的 HTML 或脚本。

## 购买安全

购买页创建订单前需校验页面、产品、方案与 `appId` 的归属关系；当前实现已进行这些基础校验。上线前还应增加请求限流、验证码/风控、订单金额服务端计算、幂等键和支付渠道真实验签，避免公开下单入口被滥用。
